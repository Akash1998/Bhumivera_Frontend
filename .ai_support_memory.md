## 2. Tamper-Proof Coupon & Promotion Architecture (Better than Amazon / Flipkart)

### 2.1 Unified Coupon Schema (`coupons` Table)
All coupon sources (Admin Panel, Spin-the-Wheel Gamification, Abandoned Cart Recovery, Referral Rewards, and Support Courtesy Coupons) share a unified, bidirectional schema in `models/couponModel.js`:
- `code` (`VARCHAR(64) UNIQUE`): Normalized uppercase code.
- `discount_type` (`ENUM('percentage','fixed')`) & `discount_value` (`DECIMAL(10,2)`).
- `min_order_amount`, `min_order_value`, `minimum_order_amount` (`DECIMAL(10,2)`): Automatically synchronized on insert/update and read via `COALESCE(min_order_amount, min_order_value, minimum_order_amount, 0)`.
- `max_discount_amount` (`DECIMAL(10,2)`): Optional cap for percentage discounts.
- `usage_limit` (`INT`): Global maximum total redemptions across all users (`NULL` = unlimited global pool).
- `per_user_limit` (`INT NOT NULL DEFAULT 1`): Strict per-customer usage cap. Defaults to **`1` (one redemption per user)** so a customer can never reuse the same coupon 10+ times even when `usage_limit` is high or unlimited.
- `used_count` (`INT NOT NULL DEFAULT 0`): Atomic global redemption counter.
- `first_order_only` (`TINYINT(1) DEFAULT 0`): Restricts coupon to customers with zero prior non-cancelled orders.
- `allowed_payment_modes` (`VARCHAR(255)`): Optional payment restriction (e.g., `ONLINE`, `COD`).
- `restricted_to_user_id` (`INT NULL`): Optional single-account lock (used for Support Apology coupons, Spin rewards, and Referral rewards).
- `reward_type` (`VARCHAR(32) DEFAULT 'standard'`): Supports `standard`, `free_shipping`, `coupon_credit`, and `referral_wallet`.
- `status` (`VARCHAR(20) DEFAULT 'active'`) & `is_active` (`TINYINT(1) DEFAULT 1`): Synchronized together on every write and status toggle.
- `expires_at` & `expiry_date` (`DATETIME`): Synchronized together on every write.
- `signature_sha512` (`VARCHAR(128)`): 512-bit cryptographic integrity hash of the coupon rules.

### 2.2 Immutable Redemption Ledger (`coupon_redemptions` Table)
- Columns: `id`, `coupon_id`, `coupon_code`, `user_id`, `order_id`, `order_number`, `discount_amount`, `order_subtotal`, `reward_type`, `status` (`'redeemed'` | `'reversed'`), `ip_address`, `user_agent`, `signature_sha512`, `redeemed_at`, `reversed_at`.
- **Frontend Checkout & Admin Controls**:
  - `src/pages/Checkout.jsx`: Full coupon input box, Available Offers quick-picker (`coupons.getAvailable` + `coupons.getMine`), Loyalty Points redemption toggle, delivery speed selector, and `couponCode` submission to `/api/orders` and `/api/payments/create-order`.
